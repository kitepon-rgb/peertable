# m3 — done・証跡・run操作を呼出しPLANで束縛する

## 実装

- `done.sh <task> --plan <plan>` を追加し、明示した plan を `PEERTABLE_PLAN` より優先するようにした。task show、run list、todo done、証跡 path は同じ plan を使う。
- 証跡本文の監査語走査と peer audit gate を撤去した。`done.sh` は room receipt、別席、固定 SHA を要求せず、既存のLattice receipt／landing検証だけを維持する。
- 現在の卓の `.team/scripts/done.sh` も template と同じ内容へ同期した。

## focused verification

```text
$ bash -n skill/templates/done.sh
$ bash -n .team/scripts/done.sh
$ cmp -s skill/templates/done.sh .team/scripts/done.sh
$ node --check experiments/done-receipt-gate-repro.mjs
$ node experiments/done-receipt-gate-repro.mjs
done-receipt-gate repro: 29/29 green
```

回帰は、room接続も監査文も無い証跡で完了できること、`--plan` が環境の互換既定を上書きすること、既存のrun receipt／landing条件を測る。
