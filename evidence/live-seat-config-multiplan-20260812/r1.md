# r1 — Aiterm managed session を正規着席へ結線

実施日: 2026-08-12

## 実装

- `aiterm-launch.mjs` を追加し、Aiterm の公開 `codex_agent` / `claude_agent` launch receipt を
  schema・provider・session_id まで検証する境界にした。
- `launch-seat.sh` は tmux 内の direct CLI launch を撤去し、上記 adapter を唯一の agent launch
  経路にした。launch receipt の session_id を `aiterm_session_id`、role とともに同じ room member
  metadata へ保存・読戻しする。direct CLI fallback は置かない。
- Aiterm が通常の project 環境で room MCP を起動できるよう、両 vendor で root room MCP の current-tree
  binding を確認する。既存の model／effort、brief、wakeup bridge、seat identity の後段契約は維持する。
- skill guide は、親が script を迂回して agent launcher を呼ばず、script 内部だけが managed session を
  正規 member に結線することを明記した。
