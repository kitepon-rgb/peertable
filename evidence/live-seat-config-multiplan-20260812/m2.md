# m2 複数PLAN・着席装備・監査席役割

実施日: 2026-08-12

## 実装

- `launch-seat.sh` はroleを受け取り、未指定時は互換の`worker`とする。roleはroom member metadataへ投影する。
- Codex席はroom登録後に`wakeup-bridge`を必須でensureし、readyにならなければ
  `SEAT_WAKEUP_BRIDGE_NOT_READY` で着席成功扱いしない。
- member案内ではsetup時のPLANを初回既定とし、task操作はLattice正本の完全修飾plan/taskで選ぶ。

  `peertable-autonomy-runtime-20260811/t4` をそれぞれ `lattice todo show --plan ... --task ...` でread-only参照した。
  旧t4への書込みはしていない。
