- Aiterm公開launch receiptを process 起動の正本とし、receipt 成功後に旧 direct CLI launch 専用の
  ヘッダ・trust dialog観測を重ねないようにした。
- 必須 room MCP の成立は従来どおり room member登録の readback で判定する。invalid receipt と
  room member未登録は typed failure のまま維持する。
- Aiterm launch prompt で既に dispatch 済みの brief は、旧 tmux paste の経路へ入らないため、
  brief turnが継続中であることを未着席理由にしない。
