## 論点として置いたもの

1. **席を managed run の worker にできるか**。案A（席を adapter 登録）／案B（worktree と lease だけ
   借りる）／案C（接続しない）を並べ、判断材料を「**誰が dispatch を所有するか**」に置いた。
   dispatch を Lattice へ渡すと **claim が機械の割り当てへ変わる**＝消費者契約が「Lattice が
   所有しない」と定めた面と衝突しうる
2. **資源の宣言に「線」を含められるか**。実書き込み観測は file の diff を見るので、
   **「同じ file を触らずに線の形を変えた」は観測に映らない**
3. **隔離は偶然の相互検査を消す**。一次資料2が反対材料で、**「隔離すれば摩擦が消える」を目標に
   してはならない**と明記した。消える検査を意図的な装置で置き換えるところまでを設計に含める
4. **run の終端で着地を見るか**（未push の取り残し）
