# t13 証跡 — Lattice test の release gate 偽赤修理

担当: rin / plan: refit-add-20260808 / 2026-08-08

## 原因

Lattice の `test/todo-plan-note.test.mjs` は child process の環境へ `NO_COLOR=1` を足す一方、親から `FORCE_COLOR` も継承していた。Node は両方が同居すると警告を stderr の JSON より前へ出すため、失敗結果を `JSON.parse(crossed.stdout || crossed.stderr)` する test が製品挙動とは無関係に落ちた。

修正前の負のコントロールは `node --test test/todo-plan-note.test.mjs` 5/6、同じ1件を含む `npm run ci` も exit 1。`NODE_OPTIONS=--no-warnings` では6/6になったが、警告を隠すだけなので採用しなかった。

## 修正

Lattice commit `83b2261`。test helper の child env を複製した直後に `FORCE_COLOR` だけを削除し、従来どおり `NO_COLOR=1` を設定した。

- 製品コードは変更していない
- 警告抑止フラグは入れていない
- stderr から JSON 行だけを拾う回避も入れていない
- 変更は `test/todo-plan-note.test.mjs` の3追加1削除だけ

## 検証

- `npm run ci`: exit 0。Node 本体・Sensor・release reachability・todo store verify を含む全 gate 完走
- `git diff --check`: exit 0
