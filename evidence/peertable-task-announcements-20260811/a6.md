# a6 完了証跡 — 通知機構を通常postの最小規則へ縮小

## 結論

旧a6が予定したtyped task eventの統合は行わない。工程通知は既存の通常room発言だけで実現し、
専用event、二重の着手通知、自動completion、遷移ID、送信者除外、member turn completedを撤去した。

## 現行仕様

1. Claim: `post(to: "all")`
2. 工程完了: `post(to: "all")`
3. 発言ターン終了: 次の行動または再確認条件を自分宛DM
4. 個人への用事: その人宛DM。宛先不明の相談: `post(to: "all")`
5. 実装・監査・readyが本当に無い時だけ、最終手段として待機を親だけへDMする。待機を`all`へ送らない

`to: "all"`の本文はroomへそのまま保存・表示する。各AIへ直接注入するのは本文ではなく、
`room.read_log`で部屋を読み状況把握する定型指示だけである。個人DMは送信者・宛先・本文を
対象席へ直接注入する。
