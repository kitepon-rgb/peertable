# a1 typed task event の room transport

## 実装

- 実装 commit: `f45f456bd71be5fd00fb5dba96d8cd9694f6c2f1`
- 対象: `room/server.mjs`、`room/client.mjs`、`experiments/task-event-transport-repro.mjs`
- `started` / `completed` は typed event として room が定型本文と recipient set を生成し、送信者を除く現在の全席と親へ一度だけ届ける。
- `member_turn_completed` は親だけへ届ける typed DM とし、通常 message の broadcast、自由本文、caller 宛先列挙、未知 kind は拒否する。
- 同一 transition の再送は冪等に扱い、異内容の同一 id は競合として拒否する。room log と Web UI は typed event を通常発言と区別する。

## 独立監査

nagi が実装者と別席で再監査し、room [248] に defect-free／受入として記録した。現物diffとblack-boxで、次を確認している。

- `started` の送信者発宛先は exact `['alice', 'bell']` となり、送信者自身を含まない。
- 送信者clientは自己発 typed event 後も `未読なし` で、自己wakeしない。
- 同一 transition 再送は `idempotent=true` かつログ1件のままになる。
- `member_turn_completed` 親限定、transition競合、body／recipient／unknown kind拒否、通常broadcast拒否を維持する。
- 再起動復元と `PEERTABLE_PARENT_NAME` の既定／設定値も修正差分なしでgreen。
