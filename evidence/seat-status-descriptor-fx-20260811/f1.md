# f1: wakeup bridge の catch-up 回帰修正

## 実装

- member 記述子の取得を非致命化した。取得失敗時は直前の member map を保ち、未登録席は
  legacy の `peer-<name>` target へ縮退する。
- 縮退は `member 記述子を更新できない…` としてログに記録する。

## 確認

- 変更前の `node experiments/bridge-catchup-repro.mjs` は `/members` の空 body を
  JSON parse して `SyntaxError: Unexpected end of JSON input` で失敗した。
- 修正後の同ハーネスは `/members` の 404 をログに出しつつ、心拍差分の検知・取りこぼし回収・
  配達判断の3項目を green にした。
- `node --check skill/scripts/wakeup-bridge.mjs` と `git diff --check` が成功した。
