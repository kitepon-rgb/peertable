# h9 — frontier連動の自律増員・安全縮退

## 実装

- `capacity-advisor.mjs` が Lattice の active と independence 検証済みready、roomのlive worker状態を同じ容量面へ投影する。
- `capacity-bridge.mjs` が差分をtyped DMとして親とreclaim対象へ送り、POST成功後だけ原子的にstateを進める。
- 親登録は member → current name→descriptor wakeup ready → capacity の順とし、親descriptor不在ではcapacityを起動しない。
- 起動時の静的seat引数を配送正本にせず、後から参加したmemberも現在のdescriptorから解決する。
- 同一frontier内ではreclaim通知済み席を、同一target中ではlaunch要求済み絶対targetを永続化し、DMで生じるbusy/idle往復・worker起動途中・claim不能席の正規退席で同じlaunchを再通知しない。
- 縮退は`target + worker_count`をwave識別子として永続化し、候補席への確認DMでidle候補が入れ替わっても同じ退役要求を再通知しない。reclaim同時pollでは通知済みにせず、次pollの安全候補で一度だけ発火する。
