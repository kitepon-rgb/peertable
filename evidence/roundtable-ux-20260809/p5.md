# p5 チャットへのログ番号表示 — 実装・検証証跡

## 結論

room Web UIの各発言へ、roomログと同じ`[seq]`を表示した。発言者metaが省略される5分以内の連投でも
番号は消えず、通常発言・DM・system発言を同じ表記で目視できる。

## 実施

- source commit: `ac952b9`
- 変更: `room/server.mjs`
  - 通常発言のbubble直下へコピー可能な`[seq]`を常時表示する。
  - system行にも本文と時刻の間へ`[seq]`を表示する。
  - 等幅数字・控えめな色で本文を邪魔せず、ログ引用の番号を目で追えるようにした。

## 検証

- `node --check room/server.mjs`: green
- `git diff --check -- room/server.mjs`: green
- 一時data dirとlocal server（`127.0.0.1:18791`）で次の4件を作成し、実ブラウザで確認した。
  - 通常発言 `[1]`
  - 同一話者・5分以内の連投 `[2]`（発言者metaが省略されても番号は表示）
  - DM `[3]`
  - system参加発言 `[4]`
- DOM上の`.seq`はexactに`[1]`, `[2]`, `[3]`, `[4]`の4件、browser consoleのwarning/errorは0件。
- 検証タブを閉じ、local serverを停止し、一時dir`/tmp/peertable-p5.g0oaGc`を削除した。
