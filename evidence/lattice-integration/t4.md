# t4 setup/teardown コネクタと立卓高速化（P3+P5）— haruka

## 何を作ったか

### P3 外部ペインコネクタ（決定53）

- **`skill/scripts/external-pane.mjs`（新規）**: 対象 project の `.lattice/project.json` へ
  `external_pane: { title:"円卓", url:<公開基底>/<room>, probe_url:<公開基底>/api/<room>/members }` を書く。
  Lattice の identity 文書はキー集合ごと検証されるため、既存欄（`schema` / `project_id` / `display_name`）を
  保った**完全な identity 文書として書き直す**。既存文書は `.team/project.json.bak` へ退避する。
  `project_id` は 既存 identity → project ディレクトリ名 の順で決める（`make-plan-input.mjs` の既定と同じ）
- **`skill/scripts/setup.sh`**: Lattice 併用モードのときだけ上記を呼ぶ。公開URL基底は `PEERTABLE_PUBLIC_URL`
  （未設定なら room サーバーの URL）。書いた URL は必ず標準エラーへ出す＝LAN URL のまま黙って壊れない。
  `setup-state.json` へ `public_url` / `external_pane` / `project_json_preexisting` を記録
- **`skill/scripts/teardown.sh`**: `.team/` を消す**前に** `project.json` を setup 前へ戻す
  （退避があれば書き戻し、無ければ削除）

### P5 立卓 script

- **`skill/scripts/launch-seat.sh`（新規）**: `<project> <name> <model> [claude|codex] [effort] [着任指示]`。
  tmux 作成（aiterm と同じソケット＝立てた席をそのまま `pty_read`/`pty_send` で読める）→ env 注入 →
  エージェント起動 → 既知ダイアログ通過 → 着席確認 → 任意で着任指示。
  **着席しなければ最後の画面を標準エラーへ出して非ゼロで落ちる**（黙って進まない）
- **`skill/scripts/make-plan-input.mjs`（新規）**: タスク定義 JSON から `lattice.plan_create_input.v4` を生成。
  `input_digest` 計算と `hard_dependencies` の `(from,to)` 昇順ソートを内蔵
  （caveat `lattice-plan-create-hard-dependencies-from-to-pointer`。手書きで2回踏んだ罠の機械化）
- **`skill/scripts/parent-join.sh`（新規）**: 親の member 登録と kickoff 投稿
- **`skill/SKILL.md`**: setup 手順を「聞き取り → script → 着任指示」へ圧縮。ダイアログの実測・0.50.0 前提の
  警告・証跡パス・シェルの罠2件を運用知識へ追加
- **`skill/templates/done.sh` / `skill/templates/member.md`**: 証跡の置き場を
  `evidence/<plan_key>/<task_id>.md` へ（task_id は campaign を跨いで再利用されるので、平置きだと
  前の campaign の監査証跡を上書きで消す。room [22] で mio が done 前に発見し、恒久修正は skill/ 配下＝
  t4 の範囲なので本 task で持った）
- **`room/client.mjs`**: `skill_bundle` 診断の必須ファイルへ新 script 4本を追加（欠けたまま green を返さない）
- **`docs/plan.md`**: 決定53 を追記し、§9.0 不可侵原則へ例外3（`external_pane`）を明記

## 途中で踏んで潰した罠（SKILL.md の運用知識へ焼いた）

- **bash で `$var` の直後に全角括弧を書くと変数が空になる**。高位バイトを変数名の一部として食うため、
  `seated: peer-testseat（…）` が `seated: （…` になり情報が黙って消えた。`${var}（…）` で閉じる
- **`python3 -c` へ `{...}` を含む式をインラインで渡すとシェルのブレース展開が刻む**。
  `json.dumps({'from':…,'to':…})` が3つに割れて SyntaxError。ヒアドキュメントで渡す
