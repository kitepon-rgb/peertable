担当 ichika。作業repoは `/Users/kite/Developer/Lattice`（commit `eeae898`「projectごとの外部ペインを配信層だけで右ペインへ差せるようにする」）。

## 何を作ったか

Latticeが「projectごとに外部ペインを1枚だけ差せる汎用の口」を持つようにした。Latticeは差された先が
何のサービスかを知らない——題名・埋め込み先URL・生存probe URLの3つだけを受け取る（決定46の分離維持・
Peertableを名指ししない）。

- `src/project-identity.mjs`
  - `.lattice/project.json` の許容キー集合を `display_name,project_id,schema` に加えて
    `display_name,external_pane,project_id,schema` へ緩和。完全一致検証のままだと `external_pane` を
    書いた瞬間に `identity_schema_invalid` で status/gantt系が全滅する（haruka の実物確認 room[17]）
  - `external_pane` は `{ title, url, probe_url }` の3欄ちょうど。title は display_name と同じ制約、
    url/probe_url は http(s) の絶対URLのみ（2048バイト以内・制御文字不可）。壊れていれば従来どおり
    `PROJECT_IDENTITY_INVALID` で落とす＝黙って無視して「差したのに出ない」を作らない
  - 新規 export `readProjectExternalPane({ repoRoot, projectId })` が
    `{ title, url, probeUrl, frameOrigin, probeOrigin }` かnullを返す。URL解析はここで閉じ、配信層は
    originを受け取るだけにした
  - `resolveProjectIdentity` の**戻り値の形は変えていない**ので既存5箇所の呼び出しは無影響
    （`{projectId, displayName, source}` のまま）
- `src/todo-gantt-live.mjs`（配信層だけ。描画部品 `renderTodoGanttHtml` は不変）
  - `liveHtml()` に第4引数 `externalPane` を足し、設定があるprojectだけ次を注入する:
    ①CSPへ `connect-src 'self' <probeのorigin>; frame-src <urlのorigin>;`
    ②`.narrative-pane` をflex columnにする小さなstyle
    ③右ペインのタブ（`data-show-external-pane`・title表示・**「概要」ボタンの左**）
    ④`data-right-panel="external"` のiframeペイン（`data-src` で遅延ロード）
    ⑤タブ切替とprobeによる既定タブ決定のcontroller
  - 注入点（CSP・`</head>`・「概要」ボタン・`<div class="right-content">`）が1つに定まらなければ
    `EXTERNAL_PANE_INJECTION_FAILED` で落ちる（`injectOnce`）。描画部品のmarkupが変わった時に
    黙って注入をやめない
  - 既定タブ判定は汎用契約: probeが200を返し、かつ**非空の一覧**（JSONが非空配列、または配列値の
    プロパティが1つ以上非空）なら外部ペイン。非200・fetch失敗・空一覧はすべて概要
  - iframeは初めて表示する時に `src` を入れる。卓が無い時は円卓を1回も読みに行かない
- `bin/lattice-dashboard.mjs`
  - render が**毎リクエストで** `.lattice/project.json` を読み `external_pane` を返す。差した／外した側
    （peertableのsetup/teardown）はdaemon再起動を要さず、reloadで反映・復帰する

### ブラウザ実測（headless Chrome for Testing 151 + CDP）

ハーネス: 実物のgantt HTMLを配信するdashboardと、円卓の代役（`/api/room-a/members` をCORS許可つきで
返し、`/room-a` にダミーページ）を立てて実際に描画させた。

| 条件 | 実測 |
| --- | --- |
| probe 200 + `{"members":[{...}]}` | 既定タブが外部ペイン（`data-view-state="external"`・panel可視・`.right-content` 非表示）。タブ順は `["円卓","概要","選択工程へ戻る","全工程一覧"]`＝概要の左 |
| CSP実物 | `default-src 'none'; connect-src 'self' http://127.0.0.1:50469; frame-src http://127.0.0.1:50469; script-src 'unsafe-inline'; style-src 'unsafe-inline'` |
| iframe寸法（1440x900） | 597x811（`.narrative-pane` 597x861 − toolbar）＝ペイン全高を占める |
| タブ往復 | 概要→`overview` / 全工程一覧→`task-index` / 円卓→`external` / 工程ノード選択→`details` / 円卓へ戻る→`external`。どの遷移でも外部ペインと `.right-content` の表示が正しく入れ替わる（MutationObserverが `data-view-state` を見て戻す） |
| probe 200 + `{"members":[]}`（卓なし） | 既定は概要。iframeの `src` は未設定＝円卓を読みに行かない。タブを押せば開ける |
| probe 到達不能 | 既定は概要（fetch失敗はconsoleに出る＝握りつぶさない）。タブを押せば開ける |
| console | 到達可能な条件では error/warning ともに 0件 |
