## publish と install

`npm publish` → `+ @quolu/lattice@0.50.0`。

**既知caveat が実際に出たので、内実を記録する。** publish 直後の `npm install -g @quolu/lattice@0.50.0 --prefer-online` は **ETARGET（No matching version found）で落ちた**。この時 `npm view @quolu/lattice version --prefer-online` も **0.49.0** を返していた。つまりこれは **ローカルキャッシュの問題ではなく registry 側の伝播待ち**で、`--prefer-online` を付けても直後は無意味だった。正しい対処は「`npm view` が新版を返すまで待ってから install」。数十秒で解消し、install 成功後 `lattice --version` = **0.50.0**。

（caveat `npm publish直後のinstallはETARGET/キャッシュ罠あり` は、キャッシュ罠と伝播待ちの2つを1つに畳んでいる。実測されたのは後者だった。）
