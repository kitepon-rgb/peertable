# t5 Codex席対応と wakeup-bridge（P4）— haruka

## 何を作ったか

- **`skill/scripts/wakeup-bridge.mjs`（新規）**: Codex 席の起床ブリッジ。room の SSE を購読し、
  その席宛または全員宛の新着（**自分の発言は除く**）を tmux の席へ素送信して起こす。
  2秒ごとに束ねて1回だけ送る（連投で席を何度も起こさない）。
  生死は Lattice ADR 0157 の作法: `.team/wakeup-bridge.json` へ自分の pid を記録し、起動時に前の記録を
  掃除する（死んでいれば消す・生きていれば SIGTERM→SIGKILL）。止まらなければ
  `WAKEUP_BRIDGE_STOP_FAILED`、SSE へ10回連続で繋げなければ `WAKEUP_BRIDGE_UNREACHABLE` で落ちる
- **`skill/scripts/launch-seat.sh`**: Codex の更新案内ダイアログ（`1. Update now`）を「2. Skip」で通す分岐を追加
- **`skill/scripts/teardown.sh`**: `.team/` を消す前にブリッジを停止する
- **`skill/SKILL.md`**: Codex 席の起動手順（stdio MCP の差し方・env 全列挙・モデル slug の注意）と
  起床ブリッジの起動/停止を手順へ。運用知識へ Codex のダイアログ2種と steering の実測を追加。
  不可侵原則へ external_pane の例外を明記（t4 で docs/plan.md へ入れた分の手順書側）
- **`skill/templates/member.md` / `member-standalone.md`**: Codex 席の注記（起床経路・作業中でも割り込む・
  自分の発言では起きない）
- **`room/client.mjs`**: `skill_bundle` 診断の必須ファイルへ `scripts/wakeup-bridge.mjs` を追加
- **`docs/plan.md`**: 決定54

## どう確認したか（すべて実機）

1. **Codex 席が円卓の会話へ参加した**: scratch project（単独モード・room `t5probe`）へ
   `launch-seat.sh <project> codexseat gpt-5.6-sol codex` で着席 →
   指示に応じて `room.post` を呼び、`codexseat → all: コデックス席、着任した` が room に載った
2. **busy 中の素送信（steering）が通った**——これが計画の第一候補で、通ったので idle 待ちは実装しない。
   席が `Working (… • esc to interrupt)` の状態で割り込みを送ると、その文言は**同じターンの中で読まれ**、
   指示どおり `codexseat → all: 割り込みを受け取った` を投稿した
3. **ブリッジの端から端まで**: ブリッジ起動 → 親が room へ投稿 → ログに
   `起こした: codexseat ← 1 件（最新 seq 5）` → 席の画面に
   `room に新着あり（bell → all）。read_unread で読むこと。` が入り、席が `room.read_unread` を呼んで
   `codexseat → all: ブリッジで起きた` を投稿した
4. **自分の発言では起きない**: 席自身の投稿（seq 6）でログに「起こした」行が増えないことを確認
5. **他人宛の DM では起きない**: `to: someoneelse` の投稿を流してもログに「起こした」行が増えない
6. **停止と掃除**: `wakeup-bridge.mjs <project> --stop` で `前のブリッジを停止した（pid …）` を出して
   process が消え、記録ファイルも消える
7. **teardown 統合**: ブリッジ常駐中に `teardown.sh` を実行 → ブリッジ停止 → `git status` 差分ゼロ・
   `.team/` も残骸なし
8. **診断**: `node room/client.mjs diagnostics` が `skill_bundle: 必須 15 ファイルが揃っている` を含め全 pass

## 途中で見つけて潰したもの

- **Codex の更新案内ダイアログは既定の選択肢が誤り**。`1. Update now` を既定のまま Enter すると
  立卓の途中で `npm install -g @openai/codex` が走る。`launch-seat.sh` が着席判定で落ちた（黙って
  Enter を連打しない設計だったので事故にならなかった）ので気づけた。1つ下の「2. Skip」を選ぶ分岐を入れた
- **モデル slug の誤りは起動時に落ちない**。`gpt-5.1-codex` は起動して TUI も出るが、最初のターンで
  `The 'gpt-5.1-codex' model is not supported when using Codex with a ChatGPT account.` の 400 が返る。
  SKILL.md に注意として書いた
