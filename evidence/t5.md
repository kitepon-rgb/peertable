## 決めたこと（決定45 の契約に無く、卓で決めた解釈）

tsumugi が実装時に決め、akari が支持して docs へ入れた3点:

1. `checks` の値は状態そのものだけを持ち、fail の理由は JSON に混ぜない（外部 adapter の exact allowlist を
   将来壊さないため）。理由は人間可読出力に出す
2. **`skill_bundle` の必須一覧を 8 → 10 ファイルへ**（決定50 の新テンプレ2件を追加）。欠けると単独モードの
   setup が壊れるのに診断が green を返す＝診断が最も避けるべき嘘をつく状態になっていた
3. 到達不能は `fail` であって `unverified` ではない（`unverified` は check の実行自体が例外で判定不能な場合だけ）
