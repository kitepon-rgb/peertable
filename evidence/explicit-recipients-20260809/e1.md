# e1 明示宛先プロトコル

## 実施

- room server は宛先省略、`to: "all"`、配列内の `all` を HTTP 400 の typed error
  `peertable.error.v1 / EXPLICIT_RECIPIENT_REQUIRED` で拒否する。error にメンバー一覧は含めない。
- 複数人宛は `to_names` のみを保存し、新規 `to: "all"` 行を作らない。既存ログの
  `to: "all"` 行は書き換えず `read_log` 互換を維持する。
- MCP client、起床ブリッジ、run bridge、親着卓、teardown、SKILL と role templates を
  明示宛先だけの契約へ揃えた。broadcast の代替は作らず、状況把握は room log の pull とした。
- 新規memberの system 発言は本人宛、run bridge の宛先不明は
  `RUN_BRIDGE_RECIPIENT_UNKNOWN` としてlocal logへ残す。
