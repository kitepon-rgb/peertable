# t11 外部ペイン喪失の再発防止

担当: kotoha / 2026-08-08 / plan `refit-pane-20260808`
対象: `skill/templates/done.sh`＋卓のローカル `.team/scripts/done.sh`（層①）／`skill/SKILL.md`（層②）

## 何が起きたか

前 campaign の受入検証が、本番 peertable repo の `.lattice/project.json` から `external_pane` を外して
「**タブごと消えて概要へ戻る・CSP 追記も消える・痕跡が1文字も残らない**」を確認したところで終わった。
確認としては正しく、**外れたこと自体は誰の間違いでもない**。漏れたのは**差し直し**で、それが人の記憶に載っていた。
結果、公開工程表から円卓が消えたまま誰も気づかず、**オーナーが見つけた**。

外れた状態は**画面から何も言ってこない**——「欄が無い project にはタブも CSP 追記も注入しない」という
Lattice 側の仕様どおりの挙動なので、**沈黙は正しい**。だから気づく仕掛けは Peertable 側に要る。

## 層① `done.sh` の1行警告

**全員が必ず通る一点**（done を打つ瞬間）に置いた。mio の未push 警告と同じ作法——**出すだけ・止めない・読めない時は黙って継続**。

判定: `.team/setup-state.json` があって `mode == "lattice"` なのに、`.lattice/project.json` に `external_pane` が無い。

```
外部ペイン未設置: 公開工程表に円卓が出ていない（差し直す: node <skill>/scripts/external-pane.mjs . <room> <public_base>）
```

**負のコントロールを先に取ってから**、正常系の「出ない」を読んでいる（決定60）。

| 条件 | 警告 | rc |
| --- | --- | --- |
| **`external_pane` が無い（今日の実際の壊れ方）** | **出る** | 0 |
| `.lattice/project.json` ごと無い | 出る | 0 |
| `project.json` が壊れている（JSON ではない） | 出る | 0 |
| 差さっている（正常） | 出ない | 0 |
| 単独円卓モード（`mode != lattice`） | 出ない | 0 |
| 卓が無い（`.team/` なし） | 出ない | 0 |
| **`python3` が PATH に無い** | 出ない | 0 |

**どの条件でも rc=0**＝`done` を殺さない。`set -e` の下なので、判定は `|| true` でガードし、
`if` 文で書いている（`[ … ] && echo` は偽の時に非ゼロを返して done.sh 自体を落とす）。
**沈黙する失敗を塞ぐ部品が同じ形で止まっては本末転倒**（mio の t2 と同じ理由）。

実運用の卓（この repo・`external_pane` は差さっている状態）で `done.sh` を叩いて**無音**であることも確認済み。
卓のローカル `.team/scripts/done.sh` にも同じ内容を反映し、正本との一致を diff で確認した。

## 層② `SKILL.md` の検証規律

不可侵原則の `external_pane` の項へ2行:

- **本番のコネクタを検証のために外さない。** 「外すと痕跡ゼロで戻る」の確認は**使い捨て project** でやる。
  **本番で外したら、差し直すまでが1手順**。外した状態は画面から何も言ってこない（仕様どおり）
- 気づく仕掛けとして `done.sh` が1行警告を出すこと（出すだけ・止めない）

直列: bell の指示どおり SKILL.md チェーン（t6→t4→t9→t3）の後に入れた。

## 未了・後続へ渡すもの

- 警告は **`done` を打つ人にしか見えない**。**卓が長時間 done を打たない間は気づけない**——本当に早く気づきたいなら
  「卓が生きている間ずっと見る」経路（親の Monitor 側か、公開面の probe）が要る。本 task の受入条件外

  どちらも**円卓が出ていない**ことに変わりはないので分岐を足していない（決定36 の過剰設計禁止）

  **解決するなら setup が `setup-state.json` へ skill パスを記録するのが素直**だが、これも受入条件外
