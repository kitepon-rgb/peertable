# c1 検査器の子client終了をpending RPCへ伝播する

## 実装

- 対象commit: 作業ツリーの `experiments/task-event-transport-repro.mjs` のみ。
- `room/client.mjs` 子プロセスの `error`／`exit` を一つのfailure状態へ束ね、未解決のpending RPCをrejectするようにした。
- 子プロセス終了後の新しいRPC呼出しも同じfailureを即時rejectし、起動失敗時に無期限待ちへ落ちない。
- 正常終了（code 0）、異常終了、signal終了、spawn errorを同じ契約で扱う。`room/server.mjs`、`room/client.mjs`、本番image、a2/k1/h9は変更していない。

## 実測

- `node --check experiments/task-event-transport-repro.mjs`: exit 0
- `node experiments/task-event-transport-repro.mjs`: exit 0、20/20 green、約0.38秒。
- harness内の起動失敗負例（存在しないclient path）: `room client exited with code 1` を有限時間内に受信し、pending RPCをreject。
- 独立監査席Ptolemy [378]: 対象1ファイル、差分 +33/−2、構文検査・20/20 harness green、正常exit／異常exit／signal／errorのpending reject契約を確認し合格。
- c1監査前の指摘 [375]（正常終了code 0をpending rejectしていなかった）は修正し、再監査で解消した。

## 境界

これはa5で発見した検査器の欠陥を工程化したcompanion planのToDoである。依存未導入時に検査器が12/19で無期限待ちになった事実を、起動失敗のbounded負例として固定した。Wave 1の本番transportや公開roomの実動smoke、a2/k1/h9のWIPはこのToDoへ混ぜていない。
