# t10 証跡 — room Web UI の Markdown 描画

担当: mio / plan: refit-ui-20260808 / 2026-08-08

オーナーが「チャット本文が表・コード・強調を記号のまま垂れ流していて読みにくい」と訴えた問題の解消。対象は `room/server.mjs` の内蔵クライアント（吹き出し描画部）のみ。

## 設計メモから1点ずらした（申告して受理済み）

設計メモは「本文を先に全 HTML エスケープしてから、生成タグだけを許す」＝**文字列を組み立てて `innerHTML` へ入れる**形を想定していた。**`textContent` のまま DOM API で組み立てる**形へ変えた（room [203] で申告 → bell [205] で受理）。

- **エスケープ漏れという失敗モードが原理的に存在しない。** 文字列連結だと1箇所 `esc()` を忘れた瞬間に穴が開く。憲法「自プロジェクト内で完結する処理は、チェックで守るのではなくそもそも失敗しないように書く」に沿う
- **既存コードのスタイルがそれ。** kotoha が t3 でこの面を書いた時、旧実装の `innerHTML` を全部落として `el()` の `textContent` に統一している（同じ理由・room [218]②）。`innerHTML` を持ち込むと、この面で初めての危険な道具を増やすことになる
- 受入の「生 HTML は通さない」は、エスケープで満たすより DOM 構築で満たす方が強い

## 何を入れたか

`room/server.mjs` の内蔵クライアントへ `md(src)` と `inline(parent,text)` を追加し、`el('div','bubble',m.body)` を `md()` の DocumentFragment 差し込みへ置き換えた。CSS も対応分を追加（`.bubble` から `white-space:pre-wrap` を外し、`pre` 側で `white-space:pre` を維持・表は `overflow-x:auto` の内部スクロール）。

対応するのは **fenced code / 表 / 箇条書き / インラインコード / `**強調**` / 改行** のサブセットだけ。**リンクは入れない**（`javascript:` スキームの検証が要るものを増やさない＝決定36 の過剰設計禁止）。**外部依存も足さない。**

**実装上の罠を1つ**: クライアント JS は `const UI = room => \`...\`` のテンプレートリテラル内に埋め込まれている。バッククォート（fenced code の検出・インラインコードの正規表現）をそのまま書くと**テンプレートが早期終端する**。`\\u0060` と書いて、**生成される JS 側でユニコードエスケープとして解釈させる**形にした——生成物にバッククォートが1文字も入らない（実測: 生成 JS 6,303 bytes 中バッククォート 0 個）。

## どう確認したか

**使い捨て server（別ポート 8811・使い捨て DATA）と Chrome for Testing（CDP 9222・temp プロファイル・拡張なし）**。本番 room にも他席にも触っていない。ブラウザ起動は room [237] で事前宣言、終了後 pid 直指定で停止（`pkill -f` は使わない）。

**第一関門（ブラウザ不要）**: 生成された client JS を HTML から抜き出して `node --check` → 構文 OK・バッククォート混入 0。

**CDP でセレクタを機械的に数えた**（目視だけで済ませない）:

## 受入(2) の意味を正確に書く

**XSS が防げているのは私の実装のおかげではない。** 実装前に現行を確かめたところ、`el()` は `e.textContent=text`（`room/server.mjs:178`・`:195`）で、**`<script>` を含む発言は既に無害なテキストとして描かれていた**。kotoha が t3 で `innerHTML` を落として `textContent` に統一した時点で安全だった。

**これを先に確かめずに作っていたら、「XSS 通りました」を成果として報告するところだった**——実際には自分で危険にしてから守り直しただけ、になる。私の受入は「**Markdown を足しても安全なままか**」であり、その意味で成立している（room [218]③ で kotoha が同じ区別を指摘、bell [205] が「受入(2)の意味は『実装後も安全なまま』へ読み替える」と受理）。

## 残課題（次に触る人へ）

- **サブセットの外**: 見出し（`#`）・引用（`>`）・番号付きリスト・リンクは**意図的に入れていない**。特にリンクは `javascript:` の検証が要るので、足すなら**スキーム allow-list を同時に**設計すること
- **表の整列指定**（`|:---|---:|`）は読み飛ばしている。区切り行はテーブル判定にだけ使い、`text-align` へは反映していない
